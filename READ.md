# Vehicle Price Prediction Historical

## Overview

This project analyzes 558,837 historical vehicle transactions to predict selling prices using multiple regression and Random Forest models.

## Dataset

- 558,837 vehicle records
- Variables include year, odometer, make, body type, condition, and transmission

## Methods

- Exploratory Data Analysis (EDA)
- Multiple Linear Regression
- Random Forest
- RMSE Evaluation
- Variable Importance Analysis

## Results

| Model | Performance |
|---------|---------|
| Regression (Model 2B) | R² = 68.0% |
| Random Forest | 78.2% Variance Explained |
| Random Forest RMSE | $7,011 |

## Key Findings

1. Odometer was the most important predictor.
2. Vehicle year was the second most important predictor.
3. Random Forest outperformed linear regression.
4. Mileage and age are primary drivers of vehicle depreciation.
